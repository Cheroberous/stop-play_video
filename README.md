# stop-play_video

Github repository of the chrome extension: [Manage video](https://chromewebstore.google.com/detail/manage-video/gchejbnnafncjgmjcbeibdbjoljpgfca)

The plugin skip every youtube advertisement and retrive a list of youtube videos playing in different tabs to show them in the popup icon on the toolbar, several functionalities to interact with videos are available.

Please pin the extension before start using it.
